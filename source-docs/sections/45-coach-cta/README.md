# تحويل · دعوة للإجراء (٦ أشكال)

اسمه في المتجر الإنجليزي: *Conversion · Call to action (6 layouts)* · مساره `home.coach-cta`

**ما يعرضه:** دعوة واضحة للخطوة التالية في ستة أشكال: استشارة، أو تواصل، أو منتج رقمي، أو عدّاد الدفعة، أو خياران، أو ثقة. العنوان والوصف والأزرار مشتركة، وحقول كل شكل تظهر معه.

**متى تضيفه:** قرب آخر الصفحة، أو بعد قسم يقنع الزائر، ليعرف ماذا يفعل بعده.

<details><summary>من دليل التاجر</summary>

دعوة واضحة للخطوة التالية في ستة أشكال تختار منها في «الشكل». العنوان والوصف والأزرار مشتركة وتبقى حين تغيّر الشكل، وحقول كل شكل تظهر معه وحده.

| الشكل | ما فيه |
|---|---|
| ١ · استشارة (الافتراضي) | لوح داكن: «ما يخرج به الزائر» نقطة في كل سطر، وبطاقة «الموعد» (نص حر؛ فارغاً تُخفى)، و«صورتك»، وزر يحجز ورابط ثانٍ. ومعه «خلفية متحركة بالألوان» اختيارية |
| ٢ · تواصل | صفوف واتساب (الرقم من إعدادات الثيم أو متجرك؛ بدونه لا يظهر الصف) والبريد (من بيانات متجرك) وصف ثالث برابطه، و«سطر الحالة» و«صورتك» |
| ٣ · منتج رقمي | «المنتج» بسعره وزر الإضافة، و«المحتوى» سطر لكل جزء (ما بعد «|» في طرفه)، و«سطر تحت الزر»، و«رابط العيّنة» |
| ٤ · عدّاد الدفعة | «المنتج» و«موعد بدء الدفعة» بتوقيت السعودية (فارغاً أو بعده لا يظهر العدّاد)، و«عدد المقاعد» والمتبقي من كمية المنتج (صفر يخفي الشريط) |
| ٥ · خياران | «الطريقان»: بطاقتان بنقاط وسعر وزر، الثانية مميّزة بشارة، ورابط تحتهما |
| ٦ · ثقة | «التقييم» بنجوم، و«مزايا الثقة» بأيقونات، وزر ورابط إلى قصص النجاح |

- **المنتج:** لـ«منتج رقمي» و«عدّاد الدفعة»؛ بدونه أحدث منتج رقمي (أو دورة للدفعة).
- **الأزرار:** «نص الزر» بلا رابط ينزل إلى قسم الاستشارات. والرابط الثاني بلا رابط ينزل إلى الأسئلة الشائعة، أو قصص النجاح في «ثقة»، أو الاختبار في «خياران».
- **مهم:** النصوص الافتراضية مثال، وفيها وعود («ضمان استرجاع ٧ أيام»، «من ٨٢٠ تقييماً»…)؛ اكتبها كما هي في متجرك فعلاً.
