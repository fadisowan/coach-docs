<li><strong>الخط الزمني والزر:</strong> «المحطات» حتى ٦، لكل محطة «السنة» و«العنوان» و«سطر تحته» و«محطة مميّزة (نقطة مشمشية)». آخر محطة تأخذ نقطة باللون الأساسي. «صفحة الزر»: اختر «صفحة تعريفية» ثم صفحتك (مثل «من أنا»)؛ يظهر الزر متى اخترت له صفحة.</li>
</ul>
