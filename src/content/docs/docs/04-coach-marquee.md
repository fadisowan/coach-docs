<details><summary>من دليل التاجر</summary>
<p>شريط نصوص يتحرك بلا توقف بين الأقسام: مستقيم، أو مائل، أو شريطان متقاطعان يتحرك كل منهما عكس الآخر.</p>
<ul>
<li><strong>النصوص والشكل:</strong> «العناصر» من ٢ إلى ١٠. «الشكل»: «مستقيم» (الافتراضي) أو «مائل» أو «شريطان متقاطعان». للشريط الثاني «نصوص الشريط الثاني»؛ احذفها كلها ليكرر نصوص الأول.</li>
<li><strong>الحركة:</strong> «اتجاه الحركة» و«السرعة» («هادئة» أو «متوسطة» أو «سريعة»). «يتوقف عند مرور مؤشر الفأرة» (على الحاسوب فقط، مطفأ). «زر إيقاف وتشغيل للشريط» (مطفأ) للالتزام الكامل بمعايير الوصول. ويثبت الشريط لمن فعّل «تقليل الحركة».</li>
<li><strong>الألوان:</strong> «حجم النص» و«الفاصل بين النصوص». «لون الشريط» يبدأ باللون الثانوي للثيم ويتبعه، و«لون النص» يبدأ بلون نص الثيم؛ وأي لون آخر تختاره يبقى كما هو.</li>
</ul>
</details>

### «السرعة»


<ul>
<li><strong>النوع:</strong> قائمة منسدلة · <strong>الافتراضي:</strong> متوسطة · المعرّف <code>pace</code></li>
<li><strong>ماذا يفعل:</strong> سرعة الشريط: هادئة أو متوسطة أو سريعة، وهي نفسها على كل الشاشات مهما كثرت النصوص.</li>
<li><strong>متى تستعمله:</strong> «هادئة» لنصوص طويلة تحتاج وقتاً لتُقرأ.</li>
