<p>اسمه في المتجر الإنجليزي: <em>Trust · As featured in</em> · مساره <code>home.coach-press</code></p>
<p><strong>ما يعرضه:</strong> سطر واحد بشعارات أو أسماء جهات إعلامية وشركاء ظهرت معهم. الجهة بلا شعار يُكتب اسمها.</p>
<p><strong>متى تضيفه:</strong> تحت الواجهة مباشرة، لتبني الثقة من أول الصفحة.</p>

<p>خيارات مشتركة في هذا القسم، مشروحة مرة واحدة في <code>../../01-shared/</code>: «خلفية القسم»، «لون الخلفية المخصص»، «صورة خلفية القسم»، «قوة طبقة اللون فوق الصورة»، «تمديد الخلفية بعرض الشاشة»، «المسافة العلوية (بكسل)»، «المسافة السفلية (بكسل)».</p>
<p><details><summary>من دليل التاجر</summary></p>
<p>سطر هادئ بأسماء أو شعارات الجهات الإعلامية والشركاء. الشعار رمادي ويأخذ لونه عند مرور المؤشر، وبلا شعار يُكتب الاسم بخط العناوين.</p>
<ul>
<li><strong>أهم الإعدادات:</strong> «العنوان في بداية السطر» (الافتراضي «ظهرتُ في»). «الجهات» حتى ٨، لكل جهة «الاسم» و«الشعار (اختياري)» (PNG أو SVG بخلفية شفافة، بارتفاع ٤٠ بكسل على الأقل) و«الرابط (اختياري)».</li>
<li><strong>مهم:</strong> الجهات الافتراضية من التصميم للعرض فقط. اكتب الجهات التي ظهرت فيها فعلاً، أو احذف القسم.</li>
</ul>
<p></details></p>


## الإعدادات بترتيبها في اللوحة




### «العنوان في بداية السطر»


<ul>
<li><strong>النوع:</strong> نص بسطر واحد · <strong>الافتراضي:</strong> ظهرتُ في · المعرّف <code>label</code></li>
<li><strong>ماذا يفعل:</strong> عنوان قصير في بداية السطر، مثل «ظهرتُ في».</li>
<li><strong>متى تستعمله:</strong> لتوضيح معنى الشعارات.</li>
<li><strong>حين يكون فارغاً:</strong> فارغاً تظهر الشعارات وحدها.</li>
</ul>

### «الجهات»


<ul>
<li><strong>النوع:</strong> عناصر متكررة (تضيفها وتحذفها وترتّبها) · <strong>الافتراضي:</strong> 5 عناصر جاهزة · المعرّف <code>logos</code></li>
<li><strong>ماذا يفعل:</strong> الجهات بالترتيب: اسم وشعار ورابط لكل جهة.</li>
<li><strong>متى تستعمله:</strong> قنوات أو مؤتمرات أو شركات تعاملت معها.</li>
<li><strong>حين يكون فارغاً:</strong> بلا جهات لا يظهر القسم عند الزوار.</li>
</ul>

<h4>«الاسم»</h4>
<ul>
<li><strong>النوع:</strong> نص بسطر واحد · <strong>الافتراضي:</strong> فارغ · المعرّف <code>logos.name</code></li>
<li><strong>ماذا يفعل:</strong> اسم الجهة. يُكتب مكان الشعار إن لم ترفعه، ويُقرأ لقارئ الشاشة.</li>
<li><strong>حين يكون فارغاً:</strong> جهة بلا اسم ولا شعار لا تظهر.</li>
</ul>

<h4>«الشعار (اختياري)»</h4>
<ul>
<li><strong>النوع:</strong> صورة ترفعها · <strong>الافتراضي:</strong> بلا صورة · المعرّف <code>logos.image</code></li>
<li><strong>ماذا يفعل:</strong> شعار الجهة، PNG أو SVG شفاف بارتفاع ٤٠ بكسل فأكثر.</li>
<li><strong>حين يكون فارغاً:</strong> بدونه يُكتب اسم الجهة.</li>
<li>شرحه تحت الحقل في المحرّر: PNG أو SVG شفاف، بارتفاع ٤٠ بكسل فأكثر.</li>
</ul>

<h4>«الرابط (اختياري)»</h4>
<ul>
<li><strong>النوع:</strong> رابط (منتج أو تصنيف أو صفحة أو رابط آخر) · <strong>الافتراضي:</strong> بلا رابط · المعرّف <code>logos.url</code></li>
<li><strong>ماذا يفعل:</strong> رابط يفتح في نافذة جديدة عند الضغط على الشعار، مثل رابط المقابلة.</li>
<li><strong>حين يكون فارغاً:</strong> بدونه الشعار بلا رابط.</li>
</ul>
