<details><summary>من دليل التاجر</summary>
<p>خطوات مرقّمة على خط، كل خطوة مرتبطة بمنتج: شارة بنوعه وسعره، وزر «أضف للسلة»، ورابط للتفاصيل. يقود الزائر من شراء إلى الذي بعده.</p>
<ul>
<li><strong>الخطوات:</strong> حتى ٥ خطوات. لكل خطوة «العنوان» و«سطر تحته» و«المنتج» و«نوع المنتج في الشارة» (نص تكتبه، مثل «دورة»). بلا منتج تظهر الخطوة بلا سعر ولا زر.</li>
<li><strong>العرض:</strong> «عند الضغط على منتج الخطوة»: «تُفتح في نافذة مع زر الإضافة» (الافتراضي) أو «تُفتح صفحة المنتج». «زر «أضف للسلة» بجانب السعر» مفعّل. «نص رابط التفاصيل» فارغاً يُخفي الرابط.</li>
</ul>
</details>
