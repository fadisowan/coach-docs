# دليل كوتش — الإصدار 1.76.1

توثيق ثيم Coach على منصة سلة، باستخدام Astro Starlight بالعربية وRTL.

الموقع: https://fadisowan.github.io/coach-docs/

## المصدر الحالي

المصدر الوحيد للمحتوى والصور هو حزمة `coach-docs-1.76.1-all.zip` التي استُوردت كاملة. حُذفت صفحات وصور ومراجع الإصدارات السابقة من النسخة الحالية؛ تبقى الإصدارات السابقة في تاريخ Git فقط.

- ٤٨ مكوّنًا للصفحة الرئيسية.
- ١٤ مجموعة إعدادات عامة، بالإضافة إلى الخيارات المشتركة.
- ٦٣ وحدة توثيق، و٧٨٢ حقلًا، و٩٧٨ زوجًا من اللوحات والنتائج.
- ١٥٤٥ صورة مطابقة لملفات الحزمة الجديدة.
- ٣٨ موضع معاينة غير مصوّرة في المصدر الجديد، موضّحة في صفحاتها. لم تُستعمل صور قديمة أو بدائل مصطنعة لتعويضها.

`source-docs/NOT-CAPTURED.md` يحفظ قائمة المصدر بالمعاينات غير الملتقطة. `release-manifest.json` يسجّل بصمات كل ملف مصدر وصورة، والمراجع الملغاة، والمواضع غير المصوّرة.

## الملفات

- `src/content/docs/docs/`: الشروحات الحالية فقط، بصيغة Markdown.
- `src/content/docs/index.mdx`: الرئيسية.
- `src/content/docs/components.md`: فهرس المكوّنات الـ٤٨ بالصور المتاحة.
- `src/content/docs/settings.md`: الإعدادات العامة والخيارات المشتركة.
- `assets/`: صور الحزمة الجديدة فقط.
- `source-docs/`: ملفات المصدر الجديدة الأصلية، دون تنفيذ التعليمات المكتوبة داخلها.
- `src/components/Head.astro`: نافذة تكبير الصور.
- `src/styles/custom.css`: الهوية والتجاوب.
- `astro.config.mjs`: العربية والمسار والقائمة.

المرجع النصي الكامل المرفق بالحزمة متاح للتنزيل من الرئيسية، باسم `coach-guide-1.76.1.md`.

## التشغيل والتحقق

```sh
npm ci
npm run validate
npm run build
node scripts/validate-build.mjs
npm run preview
```

افتح `/coach-docs/` في خادم المعاينة. يستخدم البناء مجلد صور نظيفًا ويعيد إنشاء فهرس البحث.

- `scripts/validate.mjs`: يقارن المحتوى والصور ببصمات الحزمة ويتحقق من غياب الملفات القديمة.
- `scripts/validate-build.mjs`: يفحص كل الروابط والمراسي والصور والحقول، ويطابق صفحات وصور النشر مع الإصدار الجديد بدقة.
- `scripts/starlight-test.cjs`: اختبار المتصفح للصفحات والبحث والجوال وكل الصور.
- `scripts/lightbox-test.cjs`: اختبار نافذة المعاينة بأحجام واتجاهات مختلفة.

اختبارات المتصفح تستخدم Playwright وEdge على Windows؛ يمكن تحديد حزمة Playwright عبر `PLAYWRIGHT_PATH`. أضف رابط الموقع كوسيط لاختبار النسخة المنشورة.

## النشر

كل Push إلى `main` يشغّل GitHub Actions للتحقق والبناء ونشر `dist/` إلى GitHub Pages. لا تُنشر ملفات المصدر الخام أو تاريخ Git.

## المراجعة البصرية للمعاينات

`preview-audit.json` يسجّل ثماني صفحات ذات معاينات عامة أو حالات غير مصوّرة أو لقطة غير صالحة. توضح صفحة `/preview-status/` النتيجة، وتظهر ملاحظة أسفل الصور المرجعية المشتركة. لقطة تكبير المنتج التي تعرض خطأ 404 محفوظة داخل قسم يوضح أنها لقطة مصدر غير صالحة للمعاينة. ملفات المصدر الأصلية لم تُغيّر.

`node scripts/annotate-previews.mjs` يعيد تطبيق ملاحظات المراجعة؛ ليس جزءًا من البناء المعتاد.
